# biomedical_monitoring_system
A biomedical monitoring prototype using physiological sensors and C/C++

Overview

	This project aims to develop a biomedical monitoring prototype for acquiring and processing physiological signals using sensors.
	The project will combine embedded C/C++ programming, sensor interfacing, signal processing, and systematic testing.



Objectives

	Acquire physiological measurements using a MAX30102 sensor. 
	Explore heart rate estimation from optical sensor data.
	Investigate SpO₂ estimation and its limitations.
	Develop and test embedded firmware.
	Visualize and analyze measurement data using Python.
	Document the system architecture, experiments, and limitations.



Technologies

	Embedded C/C++
	STM32
	MAX30102 optical sensor
	Python for data visualization and analysis
	Git and GitHub
